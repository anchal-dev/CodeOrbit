# 🚀 CodeOrbit – Full-Stack Coding Platform

CodeOrbit is a full-stack coding platform designed to help users practice coding problems, participate in contests, and track their performance through leaderboards.

---

## 💡 Features

### 🧠 Problem Solving
- Browse a wide variety of coding problems  
- Filter by title, difficulty, and tags  
- Track solved vs unsolved problems  

### 🏆 Contests
- Participate in coding contests  
- Compete with other users in a timed environment  

### 📊 Leaderboard
- View rankings and performance insights  
- Explore other user profiles  

### 🔐 Authentication System
- Secure login/signup functionality  
- Access control for submissions and contests  

### 🤖 AI Integration
- Ask coding-related queries inside the platform  
- Integrated with Gemini 2.5 Flash  

---

## ⚙️ Tech Stack

- **Frontend:** React, Tailwind CSS, DaisyUI, Monaco Editor  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Real-time Communication:** Socket.io  
- **Code Execution:** Judge0 API  
- **Session Management:** Redis  
- **Deployment:** Vercel, Render  

---

## 🧩 Key Learnings

- Building real-time systems using Socket.io  
- Implementing secure authentication and session handling  
- Designing scalable backend architecture  
- Integrating code execution APIs  
- Managing full-stack deployment
